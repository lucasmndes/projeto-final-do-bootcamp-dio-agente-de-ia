# Cenários fictícios para demonstração

Todos os casos abaixo são sintéticos e não representam pessoas, empresas ou operações reais.

1. Um estabelecimento fictício informa atividade diferente da observada no canal de vendas. Pergunta: quais controles gerais devem ser revisados?
2. Uma mudança tecnológica afetará a conciliação. Pergunta: quais cuidados devem anteceder a implantação?
3. Uma pessoa tenta enviar uma planilha com dados cadastrais. Pergunta: como o agente protege a informação?
4. Um padrão transacional muda de forma relevante. Pergunta: isso comprova irregularidade ou inicia uma análise contextual?
